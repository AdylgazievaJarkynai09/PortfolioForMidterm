# Название проекта

Статическая страница с карточками, поиском и фильтрацией по категориям. Работает на чистом HTML, CSS и JavaScript, без сборки и зависимостей.

## Возможности

- **Поиск в реальном времени.** Фильтрация карточек по тексту при вводе. Регистр и лишние пробелы не влияют на результат.
- **Фильтр по категориям.** Категория берётся из атрибута `data-category`, значение `all` показывает все карточки.
- **Совмещение фильтров.** Карточка отображается, только если подходит и под категорию, и под поисковый запрос.
- **Счётчик результатов.** Подсчёт карточек, прошедших фильтр.
- **Плавающая кнопка.** Закреплена в правом нижнем углу, меняет цвет и прозрачность при наведении.

## Запуск

Сборка не нужна.

**Вариант 1.** Откройте `index.html` в браузере.

**Вариант 2.** Запустите локальный сервер:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000.

## Требования к разметке

- Поле поиска: `<input id="search">`.
- Карточки: элементы с классом `card` и атрибутом `data-category`.
- Скрипт подключён с `defer` или расположен в конце `<body>`.

```html
<input id="search" type="search" placeholder="Поиск...">

<div class="card" data-category="books">Python для начинающих</div>
<div class="card" data-category="movies">Матрица</div>

<script src="script.js" defer></script>
```

## Как это работает

Для каждой карточки проверяются два условия:

```javascript
const categoryOk = category === 'all' || card.dataset.category === category;
const textOk = card.textContent.toLowerCase().includes(text);
const show = categoryOk && textOk;

card.hidden = !show;
if (show) count++;
```

Подходящие карточки остаются на странице, остальные скрываются через свойство `hidden`. Переменная `count` хранит число видимых карточек.

## Стили

Цвет кнопки задаётся CSS-переменной `--fg`, её нужно объявить в `:root`:

```css
:root {
  --fg: #111;
}

[hidden] {
  display: none !important;
}
```

Правило `[hidden]` нужно, чтобы скрытие работало даже у карточек с собственным `display` (`flex`, `grid`).

## Возможные проблемы

| Проблема | Причина |
|---|---|
| `Cannot read properties of null` | Не найден элемент `#search` или скрипт загружается раньше разметки |
| Карточки не фильтруются по категории | Нет `data-category` или значение отличается регистром |
| Карточка не скрывается | CSS задаёт `display` и перебивает `hidden` |
| Кнопка не видна | Не определена `--fg` или кнопку перекрывает другой элемент |
