OVERFLOW: AUTO

A scrollable note

Good structure makes a website easier to read. Start with useful headings, descriptive links and paragraphs that communicate one idea at a time.

CSS controls the presentation. A clear visual hierarchy helps readers find their way through the page.

This note has a maximum height. When the text no longer fits, overflow: auto makes the content scrollable.

Try changing max-height in style.css. You can scroll with a mouse, touch or keyboard when this region has focus.
